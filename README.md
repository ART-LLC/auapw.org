# All Used Auto Parts Warehouse (AUAPW)

**Trusted Partner for Automotive Services and Solutions**

AUAPW is a Next.js web application for browsing, searching, and purchasing used auto parts. It features a catalog organized by vehicle make and part category, a shopping cart, wishlist, quote requests, and more.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [pnpm](https://pnpm.io/) (recommended) or npm

### Installation

```bash
pnpm install
# or
npm install
```

### Development

```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

### Build

```bash
pnpm build
# or
npm run build
```

### Start (production)

```bash
pnpm start
# or
npm run start
```

### Lint

```bash
pnpm lint
# or
npm run lint
```

## Tech Stack

- [Next.js](https://nextjs.org/) — React framework with App Router
- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS
- [Radix UI](https://www.radix-ui.com/) — Accessible UI primitives
- [TypeScript](https://www.typescriptlang.org/) — Type-safe JavaScript
